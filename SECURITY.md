# Security

Please don't report security problems in public issues.

Report them privately through GitHub's **Report a vulnerability** button on this repository's Security tab,
or by email to security@groundkrew.com. Include what you found, how to reproduce it, and what it affects.
We will reply within a few days.

Groundcrew is built to be read-only by default: it never reads secret values, and every change to
infrastructure waits for a person's approval bound to the exact plan. Reports about any way around those
rules are especially welcome.
